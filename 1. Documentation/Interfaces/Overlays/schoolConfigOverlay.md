# schoolConfigOverlay

## Description

The schoolConfigOverlay, as the name suggests, is the overlay that allows the user to configure the school's data, such as school name, the minimum grade to pass and the amount of midterms.

## Interactivity

The schoolConfigOverlay has several interactive elements:

- A text input to introduce the name of the school.
- A text field to introduce the minimum grade to pass. The minimum grade to pass can be any number between 0 and 100.
- A text field to introduce the amount of midterms. The amount of midterms can be any number. This number will be used to create the midterms in the gradesPage and in the attendancePage.
- A button to create the school.
